CS2 — ПАРАМЕТРЫ ЗАПУСКА (Launch Options) v2
=============================================

Скопировать в: Steam -> Библиотека -> CS2 -> Свойства -> Параметры запуска:

    -fullscreen -novid -nojoy -allow_third_party_software -mutex=cs2_maxfps -exec autoexec

Значение каждого:
  -fullscreen               : эксклюзивный полный экран. ОБЯЗАТЕЛЬНО для
                              минимальной задержки (borderless = +5..15 мс).
  -novid                    : пропустить интро-видео (быстрее вход, меньше аллокаций)
  -nojoy                    : не инициализировать джойстики (убирает опрос USB-HID,
                              снижает DPC-шум; если используете руль/джойстик — уберите)
  -allow_third_party_software: НУЖЕН, если хотите оверлей Discord/других программ.
                              ВНИМАНИЕ: без него нельзя писать макросы через сторонние
                              утилиты; сам по себе FPS не меняет. Если сторонний софт
                              не нужен — УБЕРИТЕ этот параметр (меньше поверхность
                              для VAC-проблем, хотя официально разрешён).
  -mutex=cs2_maxfps         : одна копия игры на ПК с этим именем мьютекса
                              (защита от двойного запуска тестов)
  -exec autoexec            : грузить наш autoexec.cfg

НЕ ИСПОЛЬЗУЙТЕ (мифы из старых наборов / вредно в CS2):
  -high                     : конфликтует с планировщиком Win11, чаще ВРЕДИТ стабильности
  -threads N                : игнорируется в CS2
  -refresh / -freq          : иногда помогает при неправильном определении герцовки,
                              но обычно не нужен; проверьте частоту в Windows
  -vulkan                   : DirectX11 в CS2 оптимизирован лучше на обоих вендорах
  -dx11 explicit            : не требуется
  +engine_no_focus_sleep 0  : это консольная команда, не параметр запуска

Проверка после старта: консоль (~) -> "status" и включите cl_showfps 4.
